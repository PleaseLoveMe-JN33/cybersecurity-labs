## 🧪 Lab Documentation Standards

每次实验尽量按照以下结构记录：

1. **实验目标（Objective）**：这次实验要解决什么问题？
2. **实验环境（Environment）**：操作系统、软件、版本和网络环境。
3. **实验原理（Principle）**：涉及哪些技术原理？
4. **实验步骤（Procedure）**：执行了什么操作和命令？
5. **结果与证据（Results & Evidence）**：实际输出、截图和验证结果。
6. **问题分析（Analysis）**：遇到了什么问题，如何解决？
7. **安全意义（Security Relevance）**：这个实验与网络安全工作有什么联系？
8. **实验总结（Conclusion）**：掌握了什么，还有哪些不足？

## 🔐 Safety & Scope

所有安全测试和攻防实践仅在个人拥有或获得明确授权的隔离环境中进行。

- 不对未经授权的真实目标开展扫描、测试或攻击。
- 不上传真实账户密码、访问令牌、私钥等敏感信息。
- 不公开包含个人信息、真实客户数据或未脱敏内部日志的材料。
- 实验操作应记录适用范围、潜在影响和清理步骤。

## 📌 Project Philosophy

重视实验的可复现性、结果验证和技术解释。

项目不仅要能够运行，还要能够说明为什么这样运行、如何验证结果，以及如何改进。
